## Overarching Objective

Create a Jupyter Notebook that takes 3 match-up spreads, each refering to matchups between individual Pokemon decks.  The input files will be in the data folder.  The three spreads will consist of:

All = All matchups
Upper50 = Matchups between players in the Top 50% in tournament results
Upper25 = Matchups between players in the Top 25% in tournament results

The objective of this notebook is to analyze the decks on several criteria, these being:

Overall Win-Rate
Matchup Consistency (or Inconsistency)
Heavily Favored or Unfavored Matchups
Simulated Tournament Performance (Swiss)
Player Skill (Based on changing matchup performance in the Upper50 and Upper25 sheets)

The end product should create an interactive html widget that summarizes all this information.
